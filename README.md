# MITSA Global | Elevate Your Business to New Heights

Premium supplier of aromatic scent machines, paper products, cleaning equipment, and commercial refreshment solutions across the UAE.

## Development

```sh
# Install dependencies
npm intall

# Start development server
npm run dev

# Build for production
npm run build
```

## Technologies Used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
